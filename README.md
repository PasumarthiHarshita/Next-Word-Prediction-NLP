# 📝 Next-Word-Prediction-NLP

An NLP-based application that predicts the most likely next word using text preprocessing and an N-gram language model. The project demonstrates the fundamentals of Natural Language Processing by analyzing word sequences from a training dataset and generating context-aware predictions.

---

## 🚀 Features

- Predicts the next word based on user input
- Text preprocessing (lowercasing, punctuation removal, and tokenization)
- N-gram language model implementation
- Lightweight and easy to understand
- Supports custom training datasets

---

## 🛠️ Tech Stack

- Python
- Natural Language Processing (NLP)
- N-gram Language Model
